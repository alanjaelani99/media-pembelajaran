Pemasangan, Penggantian & Pengujian Perangkat Jaringan serta VLAN

Konsep Dasar Perangkat & Segmentasi VLAN

Dalam perancangan jaringan komputer modern, pengelolaan perangkat keras (seperti Router, Switch, Access Point, dan Kabel UTP) serta teknik segmentasi logika menggunakan VLAN (Virtual Local Area Network) adalah kunci efisiensi dan keamanan. VLAN memungkinkan network administrator memecah satu switch fisik menjadi beberapa jaringan broadcast terisolasi secara logis.

Perangkat & Pengujian Kabel

  • Penggantian Kabel Straight vs Cross-over sesuai standar T568A / T568B.
  • Pengujian port fisik menggunakan LAN Tester / Indikator LED Link/Act.
  • Pemasangan SFP Module pada switch enterprise untuk jalur fiber optic.

Konfigurasi VLAN & Trunking

  • Pembuatan VLAN ID (misal: VLAN 10 = Guru, VLAN 20 = Siswa).
  • Assign port switch ke Access Mode atau Trunk Mode (IEEE 802.1Q).
  • Pengujian komunikasi antar PC dalam VLAN yang sama vs beda VLAN.

Skema Pengalamatan IP, Routing Statis & Dinamis

Pengalamatan IP & Mekanisme Routing

Pengalamatan IP (IPv4/IPv6) dan Subnetting (CIDR) menentukan bagaimana host dalam jaringan saling mengenali. Untuk menghubungkan dua atau lebih subnet/jaringan yang berbeda, diperlukan perangkat router dengan mekanisme Routing Statis (dikonfigurasi manual oleh admin) atau Routing Dinamis (menggunakan protokol seperti RIP, OSPF, atau EIGRP).

Subnetting & CIDR

Menghitung Network ID, Broadcast Address, Range IP Host Usable, serta Netmask berdasarkan prefix (misal /24, /28, /30) untuk efisiensi alokasi IP.

Routing Statis vs Dinamis

Routing statis ideal untuk jaringan kecil/sederhana. Routing dinamis (OSPF) otomatis memperbarui jalur routing saat terjadi perubahan topologi.

Konfigurasi NAT, Proxy Server, Manajemen Bandwidth & Load Balancing

Layanan Gateway, Keamanan & Optimalisasi Jaringan

Layanan tingkat lanjut pada router/server gerbang meliputi NAT (Network Address Translation) untuk akses internet publik, Proxy Server untuk caching & filtering konten, Manajemen Bandwidth (Queues/HTB) agar pembagian internet adil, serta Load Balancing untuk mendistribusikan trafik ke beberapa ISP.

NAT & Proxy

SNAT/Masquerade menerjemahkan IP lokal ke IP publik. Proxy menyimpan cache halaman web untuk mempercepat akses dan memblokir situs terlarang.

Bandwidth & Load Balancing

Simple Queues / PCQ mengatur batas kecepatan download/upload klien. ECMP atau PCC Load Balancing menggabungkan dua jalur ISP.

Troubleshooting & Dokumentasi Jaringan

Metodologi Troubleshooting & Dokumentasi

Troubleshooting adalah proses sistematis untuk mendiagnosis dan memperbaiki gangguan jaringan. Langkah dimulai dari analisis gejala (Physical layer, Data link, Network, hingga Application), identifikasi akar masalah, perbaikan konfigurasi/perangkat, pengujian ulang (testing), dan membuat Dokumentasi Jaringan (Network Log & Topologi Diagram).

Top-Down & Bottom-Up Model

Metode OSI Layer troubleshooting: Bottom-Up (dari kabel fisik ke aplikasi) atau Top-Down (dari aplikasi ke fisik).

Dokumentasi Perbaikan

Pencatatan waktu gangguan, penyebab kerusakan, tindakan korektif yang diambil, dan hasil verifikasi pengujian ulang.
